## Getting help

For a reproducible PhysiCelldFBA problem report, include:

- repository commit;
- operating system and architecture;
- compiler version;
- sample/Make target and executable;
- XML and SBML filenames;
- full error message or solver status;
- smallest configuration that reproduces the issue.

Use the PhysiCelldFBA repository issue tracker for extension-specific defects and the PhysiCell community channels for general PhysiCell modelling questions.
