# cancer_core_metabolism

A 3-D vessel-like section model in which each cell runs dFBA against a trimmed core model of
MCF7 metabolism (Zielinski et al., 2017), coupled to oxygen and nutrient gradients in the
microenvironment. Used to study how spatial oxygen/nutrient availability shapes flux distributions
across the vessel.

## Build & run

From the repository root:
```bash
make cancer-core-metabolism
make
./cancer-core-metabolism                      # default FBA config                  -> output/
./cancer-core-metabolism config/PhysiCell_settings_pfba.xml   # pFBA variant         -> output_pfba/
```

The default run simulates 72 h (`max_time` 4320 min) with 6 OpenMP threads, writes full data every
60 min and SVG snapshots every 10 min.

## Contents

| File | Description |
|---|---|
| `config/MCF7_Zielinski_2017_core_trimmed.sbml` | Trimmed MCF7 core metabolic model (SBML), loaded via `sbml_filename` in both `PhysiCell_settings.xml` and `PhysiCell_settings_pfba.xml`. |
| `config/PhysiCell_settings.xml` | Default configuration (FBA); writes to `output/`. |
| `config/PhysiCell_settings_pfba.xml` | Alternate configuration running parsimonious FBA (pFBA) instead of plain FBA; writes to `output_pfba/`. |
| `config/MCF7_core.yaml`, `config/MCF7_core_pfba.yaml` | dFBA definitions (substrates, exchanges, growth and death model; the pFBA one adds `secondary_objective`) of the two settings files; inputs for `addons/dFBA/utils/dfba_configurator.py` (see `addons/dFBA/utils/README.md`). |
| `config/cells_column.csv` | Initial cell positions loaded by both settings files; generated by `scripts/generate_cell_column.py` (a voxel-aligned 3-D grid along the substrate gradient). |
| `custom_modules/custom.cpp`, `custom.h` | Cell type setup and the dFBA coupling step. `setup_tissue` loads positions straight from `config/cells_column.csv`; the `create_cell_sphere_positions`/`create_cell_disc_positions` helpers in this file are defined but not called. |
| `scripts/generate_cell_column.py` | Standalone generator for `config/cells_column.csv`. |
| `scripts/preprocess_dfba_model.ipynb` | COBRA-based model preparation notebook that produced the original dFBA YAML (`addons/dFBA/utils/generate_dfba_yaml.py` is its command-line version). **Currently broken**: it reads `../config/cells_large.csv`, which no longer exists in this project. |
| `scripts/oxygen_dependency_experiment.ipynb`, `reduced_cost_analysis.ipynb` | Standalone COBRA-based model-curation notebooks (FVA, pFBA reduced-cost analysis); not part of the figure pipeline below. |
| `scripts/cancer_tissue_figures.ipynb` | Figure pipeline entry point: imports `figure_generation.py`, which imports `plot_cancer_tissue_spatial.py` and `plot_cancer_tissue_spatial_gif.py`, which import `plot_cells_spatial.py` and `plot_exchange_profiles.py`; `plot_cells_spatial.py` imports `composite_figure_style.py`. Path resolution (`figure_paths.py`) assumes a PhysiCelldFBA checkout and defaults the PhysiCell output directory to `output` relative to the notebook's working directory — i.e. the top-level `./output` produced by `make cancer-core-metabolism && make` run from the repo root. |

## Figure reproducibility

The notebook sets `TIME_POINT = 72.0` h, the time point of the supplementary panels, and writes to
`output/fig/`.

| Manuscript figure | Panels | Script | XML input | Expected output |
|---|---|---|---|---|
| Main Figure 5A (growth rate and viability near the vessel) | Spatial map | `scripts/cancer_tissue_figures.ipynb` (growth-rate cell) | `config/PhysiCell_settings.xml` | `output/fig/growth_rate_72h.svg` |
| Main Figure 5B (net uptake and secretion against distance to the vessel) | Profile grid | same notebook (`--net-export-rates` cell) | same | `output/fig/net_export_rates_grid_72h.svg` |
| Supplementary Figure S8 (extracellular concentration gradients, 15 metabolites) | Concentration grid | same notebook (`--concentration-grid` cell) | same | `output/fig/substrate_concentration_grid_72h.png` |
| Supplementary Figure S9 (uptake heatmaps by phenotypic zone) | Five processes: O₂, glucose, glutamine, glycine, lactate | `python scripts/figure_generation.py --output-dir output --fig-dir output/fig --time-point 72 --uptake-stack` | same | `output/fig/uptake_stack_72h.png` |

The notebook's final cell also writes `growth_rate.gif`, `uptake_stack.gif` and `substrate_profiles.gif`
(full time series). These are supplementary animations and are not individually numbered in the
manuscript. `output/fig/` is created relative to `OUTPUT_DIR` (see Build & run).
