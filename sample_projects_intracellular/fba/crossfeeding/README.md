# crossfeeding

A two-species syntrophic crossfeeding model: *Clostridium beijerinckii*
(`config/sbml_models/C_beijerinckii_model_iCB925_trimmed.xml`) and *Methanosarcina barkeri*
(`config/sbml_models/M_barkeri_model_iMG746_trimmed.xml`) each run dFBA with species-specific
post-update coupling (`post_update_intracellular_c_beijerinckii`,
`post_update_intracellular_m_barkeri`), exchanging metabolites (e.g. H2, acetate) through the
shared microenvironment.

This project is actively developed on the `crossfeeding_dev` branch; this directory reflects its
state on `development` as of this branch's sync.

## Build & run

From the repository root:
```bash
make crossfeeding
make
./crossfeeding
```

The default run simulates 50 h (`max_time` 3000 min) on a 1.25 µm voxel grid (2-D, ±100 µm) and writes
full data and SVG snapshots every 30 min to `./output/`.

Figures are regenerated from a simulation output folder via
`scripts/paper_figures/run_paper_figures.py` — see `scripts/paper_figures/README.md`.

## Contents

- `config/sbml_models/` — the two trimmed genome-scale models, loaded via `sbml_filename`
  in `PhysiCell_settings.xml`.
- `config/PhysiCell_settings.xml` — simulation configuration (the only config; a byte-identical
  `PhysiCell_settings_crossfeeding.xml` duplicate was removed).
- `config/sbml_models/yaml/crossfeeding.yaml` — dFBA definition of both species (substrates, exchanges,
  growth and death model); input for `addons/dFBA/utils/dfba_configurator.py` with `--sbml-folder config/sbml_models`.
- `config/200cells.csv` — initial cell positions for both species.
- `config/rules.csv` — PhysiCell cell-behavior rules.
- `custom_modules/custom.cpp`, `custom.h` — species-specific dFBA coupling, Dirichlet-node
  substrate control, and the cross-feeding exchange logic.
- `scripts/paper_figures/` — self-contained figure-reproduction pipeline (own `README.md`,
  `requirements.txt`, and `run_paper_figures.py`) for the manuscript's crossfeeding panels. See
  that README for prerequisites (including the `pctk` MultiCellDS reader) and usage.

## Figure reproducibility

All manuscript panels from Figure 6 come from one simulation run (`./crossfeeding`) and one call to
`scripts/paper_figures/run_paper_figures.py --output-dir <sim_output_dir> --results-dir ./figures
--max-hours 50` (see `scripts/paper_figures/README.md` for prerequisites, notably `pctk`).

| Manuscript figure | Panels | Script | XML input | Expected output |
|---|---|---|---|---|
| Main Figure 6B (biomass volume of both populations) | B | `run_paper_figures.py` | `config/PhysiCell_settings.xml` | `figures/biomass/biomass_combined_0_50h.png` |
| Main Figure 6C (population net export, CB and MB) | C (the Results text also cites 6D) | same | same | `figures/fluxes/fluxes_combined_net_export_fmol_s_0_50h.png` |
| Main Figure 6E (initial and final growth rate, H₂ and acetate fields) | E | same | same | `figures/gradient_fields/0_50h/microenvironment_initial_final_growth_H2_acetate_per_frame.png` |

Not generated by the shipped scripts: Main Figure 6A (schematic), Supplementary Figures S10 and S11
(five-timepoint compact layouts), and Supplementary Video S4. The pipeline also writes
`substrate_time_series_reduced.png` and a three-column `_mid25h` variant of the spatial composite,
which are not shown in the manuscript.
